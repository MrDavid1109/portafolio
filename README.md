# Portafolio de David Melo Boullon

Web personal con las tres facetas: programador, profesor y coordinador.

## Arrancar

```bash
npm install
npm run dev      # servidor local con recarga
npm run build    # genera la carpeta dist/
```

## Dónde editar

- `src/data.js`: todo el contenido (ramas, formación, stack, cifras, cintas). Los textos marcados como "ejemplo" hay que sustituirlos.
- `src/style.css`: diseño y animaciones CSS.
- `src/main.js`: interacciones (loader, menú, cursor, scroll, contadores).
- `CLAUDE.md`: contexto del proyecto y hoja de ruta para Claude Code.
